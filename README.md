**Spēles apraksts:**

Circus Game ir vienkārša spēle, kuras darbība norisinās cirkā. Spēlētājs vada personāžu, kurš pārvietojas pa spēles laukumu un krāj punktus.
Spēlē ir iestatījumu izvēlne, kurā var mainīt skaņu un ekrāna izšķirtspēju, kā arī pauzēt spēli. Spēlētājs saņem punktus, kas ir atkarīgi no precīzo metienu skaita un laika, kas nepieciešams, lai izietu līmeni.
Spēles rezultāti tiek saglabāti rekordu tabulā, kurā tiek parādīts spēlētāja vārds un iegūtie punkti.
